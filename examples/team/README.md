# 团队分布示例

单分类、商务蓝。适合团队「关于」页或远程办公主页。

## 文件

- `index.html` — 页面结构 + 样式
- `data/pins.json` — 数据

## 布局

- 左侧：地球（560px）
- 右侧：成员列表（320px）
- 窄屏时纵向堆叠

## 修改

1. 编辑 `data/pins.json`，替换为团队成员坐标
2. 修改左侧 `.members` 中成员信息
3. 更新顶部 `.badge` 数字
4. 可调整 `.layout` 的列宽

## 扩展

- 点击地球标记时，可进一步在成员列表中高亮对应成员（需自行监听 `marker:click`）
- 若成员过多（> 20），建议改用列表视图或分页

## 数据量

8 个成员约 600 字节，属于 inline 范围。
若团队规模扩至 100+ 人，建议改为 `data-src` 引用外部 JSON。
