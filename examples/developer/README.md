# 开发者主页示例

双分类、极简灰。适合个人主页的「About」页。

## 文件

- `index.html` — 页面结构 + 样式
- `data/pins.json` — 数据

## 风格要点

- 等宽字体（monospace）
- 无装饰、无阴影、1px 边框
- 提示符前缀 `$ ` 与路径 `/about`
- 双分类：居住（蓝）+ 旅行（橙）

## 修改

1. 编辑 `data/pins.json`
2. 修改 `.prompt` 路径
3. 修改 `.meta` 中的统计

## 提示

若想完全隐藏图例，将 `legend="true"` 改为 `legend="false"`。
