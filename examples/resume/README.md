# 简历示例

双分类、打印友好。适合作为简历的补充材料，或独立展示。

## 文件

- `index.html` — 页面结构 + 样式
- `data/pins.json` — 数据

## 特色

- 顶部信息条（姓名 / 职位 / 联系方式）
- 3D 地球（360px，紧凑）
- 时间轴展示居住与教育
- **打印优化**：`@media print` 去除多余留白，适配 PDF 导出

## 打印为 PDF

浏览器「打印 → 另存为 PDF」即可。

注意：地图在静态 PDF 中不可交互，但可作为缩略图展示。

## 修改

1. 编辑 `data/pins.json`
2. 修改 `<header>` 中的姓名、职位、联系方式
3. 修改时间轴 `.timeline` 中的经历
4. 修改「技能」段落

## 部署

- 独立部署：作为「关于」页的补充
- 附加到现有简历：`<iframe src=".../examples/resume/">`

## 隐私建议

简历公开时建议开启隐私模式，避免精确到家庭住址：

```json
{
  "config": {
    "privacy": { "cityOnly": true }
  }
}
```
