# 隐私与安全

## 数据流向

**默认：所有数据在浏览器本地处理，不上传任何位置信息。**

```
用户输入（JSON / CSV / GeoJSON）
        ↓
   浏览器内解析
        ↓
    渲染地球
```

- 无服务端上报
- 无第三方统计脚本
- 无 Cookie 追踪

## 网络请求

组件运行时会发起以下网络请求：

| 目标 | 用途 | 可关闭 |
|---|---|---|
| MapLibre GL JS（jsDelivr） | 地图引擎 | 是（自托管） |
| 底图瓦片（OpenFreeMap） | 地图样式 | 是（自托管瓦片） |
| 你的 JSON 文件（若用 `data-src`） | 数据 | 是（改用 `data-pins`） |

**不发送你的位置数据给以上任何一方。**

## 隐私模式

若你希望进一步模糊位置：

### 坐标模糊（`privacy.blur`）

在指定公里半径内随机偏移坐标：

```json
{
  "config": {
    "privacy": { "blur": 10 }
  }
}
```

- 单位：公里
- 结果确定（同一条目每次渲染相同位置，保证视觉稳定）
- 可用于"不想精确到街道"的场景

### 仅显示城市（`privacy.cityOnly`）

坐标保留 2 位小数（约 1km 精度）：

```json
{
  "config": {
    "privacy": { "cityOnly": true }
  }
}
```

**两者可叠加。**

## 短链托管（v1.1 预告）

v1.1 将提供短链托管服务：你上传 JSON，获得 `data-id`，嵌入代码只写一个 ID。

- **存储内容：** 仅 JSON 配置，不含个人身份信息
- **访问控制：** 仅通过 8 位随机 ID 访问
- **删除：** 可随时删除，删除后立即失效
- **不售卖给第三方**

## 自托管

若你的场景需要完全离线 / 内网部署：

1. 下载 `maplibre-gl.js` 与 `maplibre-gl.css`，用 `maplibre-url` 属性指定本地路径
2. 用 `data-pins` 内联数据（不需要外部文件）
3. 底图样式可通过 `style` 字段切换到自托管瓦片

## 免责

- 本工具不存储你的数据
- 若你使用第三方底图服务，适用其隐私政策
- 请勿在公开页面展示精确的家庭住址等敏感位置
